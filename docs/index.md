# Circuit Devices

Circuit Devices is being built as the conditional specialist repository for semiconductor device physics, `DEVSIM` TCAD simulation, wafer-acceptance-test scribe-line anchoring and `OpenVAF-Reloaded` `OSDI` compact-model extraction and qualification — operating completely deterministically without requiring AI. Its current executable surface is repository validation tooling. It has no installed TCAD study runner, compact-model extractor, OSDI compiler wrapper or qualified record schema.

Circuit Devices is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.
